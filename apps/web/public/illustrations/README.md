# Workspace illustrations

Original generated artwork created for AgentStack: porcelain and frosted lavender objects representing screens, visual assets, feedback, delivery, knowledge and account security. No third-party brand or client material is included. These assets are distributed under the repository's Apache-2.0 license.

The application uses transparent 384px WebP images with fixed layout dimensions. Render them as decorative images beside real text labels; do not use an illustration as the only accessible name or status indicator. Raw generation files are not shipped in the web bundle.
