# Workspace illustrations

Original generated artwork created for AgentStack: ivory ceramic and warm amber glass objects representing screens, visual assets, feedback, delivery, knowledge and account security. No third-party brand or client material is included. These assets are distributed under the repository's Apache-2.0 license.

The application uses transparent 768px WebP images with fixed layout dimensions. Render them as decorative images as part of the card composition with a protected text area; do not use an illustration as the only accessible name or status indicator. Raw generation files are not shipped in the web bundle.

## Warm orange series (2026-11-06)

Generated with the built-in image generation tool for AgentStack. Transparent raster originals were optimized as WebP, preserving alpha. UI use is decorative; accessible labels remain text. No customer content was used. All six assets share amber glass, burnt-orange accents, ivory ceramic and graphite structural edges, with studio lighting and no logos or readable text.

Prompt pattern: “Premium original cohesive 3D dashboard illustration for a developer workspace. [SUBJECT]. Warm burnt orange and amber translucent glass, ivory ceramic panels, subtle graphite structural edges. Crisp bevels, soft studio lighting, three-quarter perspective. Real transparent background, no colored square backdrop, square composition with subject filling about 85%. No purple/pink, text, logo or watermark. Large decorative artwork for the right side of a card.”
