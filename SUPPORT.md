# Getting help

Use [Discussions](https://github.com/builtx-pro/agentstack/discussions) for installation questions, agent integration help and early ideas. Include the AgentStack version, installation method, operating system and a small sanitized example. Search existing discussions first.

Use [Issues](https://github.com/builtx-pro/agentstack/issues/new/choose) for reproducible bugs, documentation corrections or concrete feature proposals. Describe expected and actual behavior. Do not publish secrets, private project exports or customer screenshots. Share synthetic examples and only the relevant redacted log lines.

Security reports use [private vulnerability reporting](SECURITY.md). Commercial inquiries can use the contact options on [BuiltX](https://builtx.pro). Community support has no guaranteed response time; a reproducible report or a focused PR makes it easier to help.
