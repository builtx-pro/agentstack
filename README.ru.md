# AgentStack

Рабочее место для разработчика и ИИ-агента: отсмотреть готовые экраны, оставить точную правку, проверить результат и видеть состояние проекта.

[English](README.md) · [Установка](docs/runbooks/installation.md) · [Подключение агентов](docs/agents/README.md)

## Как это работает

1. Импортируете экраны, сценарии и иллюстрации или добавляете их через интерфейс.
2. Открываете нужный экран. Слева изображение, справа комментарии к конкретной версии.
3. Просите своего агента разобрать замечания. Он читает правила проекта через MCP или CLI и берёт задачу в работу.
4. Агент исправляет исходный код, проверяет результат и прикладывает описание и доказательства проверки.
5. Вы принимаете работу либо возвращаете замечание. История сохраняется.

Комментарий может оставить разработчик, дизайнер или заказчик. Сохранение комментария само по себе не запускает модель и не расходует токены.

## Что входит

- Экраны по пользовательским сценариям, альтернативные состояния, поиск, теги и темы.
- Библиотека ассетов: иллюстрации, версии файлов, связанные экраны и обсуждения.
- Документация и правила агентов с Markdown-редактором и чекбоксами.
- Волны, эпики, спринты, истории, фичи и предложения с прогрессом по реальным задачам.
- Несколько проектов с отдельными правами администратора, разработчика и заказчика.
- История изменений, архив, сравнение версий и восстановление содержимого новой версией.
- MCP, CLI, SDK, текстовый контекст и переносимые инструкции для агентов.

Агент не может принять собственную работу или незаметно переписать правила. При одновременном редактировании сервер обнаруживает конфликт версий.

## Запуск у себя

Нужны Git, Docker с Compose и Node.js 22.22+.

```sh
git clone https://github.com/builtx-pro/agentstack.git
cd agentstack
node tools/setup/init-env.mjs --email you@example.com
docker compose up -d --build
cat .data/bootstrap-password | docker compose run --rm -T bootstrap
```

Откройте http://localhost:4311. Email задаётся при установке, уникальный пароль находится в `.data/bootstrap-password`. Перенесите его в менеджер паролей. Общего пароля по умолчанию нет.

Создайте проект и импортируйте папку `examples/starter` через Settings → Import. Это вымышленный пример восстановления доступа с экранами, ассетом, правилами и планом.

Подробности HTTPS, резервного копирования и восстановления: [инструкция](docs/runbooks/installation.md). Токены и клиентские материалы нельзя помещать в публичный репозиторий.

## Для агентов и участников

Начните с [AGENTS.md](AGENTS.md), [набора инструкций](agent-kit/README.md) и [документации MCP/CLI](docs/agents/README.md). Исходный код проекта агент меняет у вас, сервер не выполняет произвольные команды из комментариев.

Монорепозиторий на TypeScript: React, Mantine, CSS Modules, TanStack Router/Query, Fastify и PostgreSQL. Разворачивается приложением и базой без обязательных Redis или Kubernetes.

Статус: первоначальная реализация проходит выпускные проверки и первую приватную миграцию. MCP работает через stdio, обмен с Git запускается явно. Встроенного автономного запуска моделей и автоматической отправки приглашений по email нет.
