# Domain glossary

| Term | Meaning |
|---|---|
| Installation | One self-hosted deployment, containing private projects |
| Project | Authorization and collaboration boundary |
| Membership | User role in one project |
| Target | Versioned object that can be discussed |
| Screen | Stable interface state identity; variants/revisions represent appearances |
| Flow | Ordered screen path with alternative states |
| Asset | Versioned visual file with usage references |
| Review item | A concrete requested change attached to a target/revision |
| Evidence | Attributed report of checks and result; not automatically proof |
| Document | Markdown knowledge with revisions and visibility |
| Rule | Agent instruction document whose changes need human acceptance |
| Wave | A grouping of epics |
| Epic | Group of stories delivering a capability |
| Story | Unique unit counted in project progress |
| Sprint | Execution grouping of stories |
| Feature | Product capability linked to stories, never double-counted |
| Proposal | Feature/fix request awaiting triage |
| Revision | Immutable content snapshot |
| Audit event | Immutable attributed change record without secrets |
| Archive | Reversible removal from active scope, preserving data |
| Restore | New revision based on old content; never history deletion |
