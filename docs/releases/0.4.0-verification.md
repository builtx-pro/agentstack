# 0.4.0 workspace organization and task boards

## Delivered behavior

Account and project settings use responsive section navigation with first-visit loading and retained drafts. Standard form/filter/button controls are 42px; secondary icon actions have explicit accessible names. The default accent for new preferences is warm orange; saved accents are preserved. Original transparent 768px artwork is composed into project and overview cards with readable content areas.

Planning groups expand to show linked work, progress and checklists. Markdown descriptions render safely by default and have an inert source mode. Documentation/rules load cursor pages of 30 with server search, skeletons, retry and a manual continuation fallback. An intersection latch prevents repeated automatic pages when the visible layout does not grow. Desktop/mobile screen frames can be filtered through a shareable URL; wide web previews preserve their aspect.

Project stories and agent review notes have separate boards. Agent cards follow actual claim/submission/acceptance events; the board does not execute an LLM or accept its result. My tasks combines owner-private work and currently accessible assigned project stories. Personal edits are versioned, retry-safe and audited; conflict recovery keeps the draft and lets the user explicitly review a newer saved version. Project task edits retain existing permissions.

## Regression fixes found during integration

Empty optional task/document filters are omitted rather than sent as empty exact-match values. Every private task mutation invalidates its history. The continuation observer survives conditional sentinel mounting without draining pages. Draft conflict recovery fetches the current task and requires an explicit choice before using its version. CI additionally exposed a narrow-screen Russian action overflowing with wider system-font metrics. The hero action now wraps within its card; an enlarged-text regression reproduced the failure at 427px before the fix and passes at a 390px viewport after it. Existing toolbar tests now assert the agreed 42px control height; document navigation legitimately adds one bounded query rather than reloading the whole project.

## Migration and operation

Schema 6 adds owner-scoped personal task/history tables and a narrow assigned-story SELECT policy. It changes the default accent only for newly initialized account profiles. No customer object/file/comment migration is required.

Back up the schema-5 database, immutable files and protected configuration before upgrading. Schema-5 releases fail the exact readiness check on schema 6; use a schema-6-compatible application for rollback or a forward fix. Never restore an older database over newer user writes. The full clean-VPS apt/DNS/public-ACME rehearsal remains unverified as documented in 0.3.0; this release does not claim that gap closed.

Deployment and the private self-review catalog refresh are verified separately in the operator journal and release notes. Human acceptance is not inferred from passing tests.
