## Actual integration checks

- Fresh Docker installation, unique administrator bootstrap and rejection of repeat bootstrap.
- Browser login, project/catalog rendering, revision-bound comments and persistence after reload.
- Real document creation, safe Markdown rendering, checkbox update, edit, comparison, restore, archive and unarchive. Versions advance without losing earlier records.
- Actual stdio MCP process against the API: tool discovery, context, claim, evidence submission and human acceptance; agent self-acceptance rejected.
- Legacy screen/asset bookmarks survive login and select the mapped comment under current permissions.
- Large private catalog import, full file hash/size reconciliation, all active screen images present, exact comment/event preservation and idempotent replay. Customer materials are excluded from this repository.
- Database/file backup restored into a separate empty installation. All table counts, object/note histories and sample file bytes match. Customer isolation and anonymous file denial verified after restore.
- Upgrade from schema 2 to 3 preserves old unknown rule snapshots. Claims capture current rules; changed rules require an explicit new claim before submission.
- A terminated idle PostgreSQL backend does not terminate the API's database client; a subsequent query succeeds. Disk-full upload cleanup is covered separately from exclusive-create collisions.

Independent security, database, operations, test and publication-hygiene reviews found issues during implementation. The recorded blocking findings were fixed and checked again before publication.

## Operational boundaries

- Stdio MCP uses project-scoped tokens; no remote OAuth MCP or automatic model runner is bundled.
- Git exchange is explicit and version checked. The server does not execute repository shell commands.
- Active external previews are sandboxed. Authenticated previews require their own compatible origin/resource-access setup. The first Concepts migration uses immutable screenshots for every palette instead.
- Historical Concepts screen revision IDs did not exist and are not invented. Imported author labels remain unverified; original private identifiers stay in operator-only provenance.
- Uploaded content is not governed by the engine's Apache-2.0 license.

The first production cutover is recorded separately by the operator. A passing local release gate alone does not mean a live deployment has switched.
