## Operational boundaries

- Stdio MCP uses project-scoped tokens; no remote OAuth MCP or automatic model runner is bundled.
- Git exchange is explicit and version checked. The server does not execute repository shell commands.
- Active external previews are sandboxed. Authenticated previews require their own compatible origin/resource-access setup. The first Concepts migration uses immutable screenshots for every palette instead.
- Historical Concepts screen revision IDs did not exist and are not invented. Imported author labels remain unverified; original private identifiers stay in operator-only provenance.
- Uploaded content is not governed by the engine's Apache-2.0 license.

## Verified production cutover

The first private deployment switched on 2026-11-05 from an immutable legacy static catalog to AgentStack revision `62cc87e`, after GitHub CI passed. Operator-only evidence records the source/file manifests, database snapshots, exact comment/event reconciliation, image digest and routing rollback procedure.

Live HTTPS browser checks confirmed login, legacy bookmarks through login, the exact imported comment, resource documents/history, screen search and mobile layout. Both retained presentations, their original PDFs, the 3D editor's lazy model packs, animation, PNG export and URL-state reload passed. All original static files matched their preflight hashes after switching. Existing legacy credentials remained unchanged after removing the temporary verification account.

Read-only production MCP verification discovered 15 tools, saw only the granted project, and read its current context and review queue. Mutation/acceptance tests ran on isolated installations, not on customer production feedback. Cached legacy Basic credentials do not interfere with the new session/Bearer API; unauthenticated and invalid Bearer requests remain denied.

The container regression test builds from restrictive source permissions and verifies non-root access. Bulk import timeouts are configurable and do not trigger automatic mutation retries. A timed-out import was reconciled against committed data before any further operation; a client timeout is not proof of rollback.
