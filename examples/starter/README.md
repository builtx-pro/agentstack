# Lumen synthetic starter

A fictional recovery flow, four full-size mobile screens, one illustration, project documents and a small delivery plan. These are example records, not performance claims or real customer work.

Import `manifest.json` using the CLI into an empty project. The CLI verifies each file hash and resolves stable object/file keys before sending the transactional catalog import. Import requires a human-authorized operator for rules and completed example stories; ordinary agent tokens cannot bypass human acceptance by importing a rule or a completed task.

Suggested walkthrough:

1. Open Screens and select “Lost second factor or phone”.
2. Open “Choose a recovery method” and leave a note about a button label.
3. Open Assets and see the security illustration and its screen usage.
4. Read the project brief and inspect the plan/checklists.
5. Use a project-scoped MCP token to read and claim the note.
6. Submit the verified result, then accept or reopen it in the web interface.
7. Compare versions and archive/restore an object to inspect its history.

All example content is deliberately small enough to inspect and replace with your own project.
