# STORY-011-01: Validate legacy import

As a operator, I want to dry-run a consistent catalog/database snapshot, so that I can reconcile every migrated object.

## Acceptance
- Given a legacy export with asset comments, when import runs twice, then counts, events and mappings match without duplicate comments.
- Given an unauthorized project or hidden target, when the operation is attempted through any exposed adapter, then it is rejected without disclosing content.
- Given a stale expected version, when a mutation is retried, then the caller receives a conflict and no data/history is overwritten.
